This feature is exclusive to [_Java Edition_](https://minecraft.wiki/w/Java_Edition "Java Edition").

_[Minecraft: Java Edition](https://minecraft.wiki/w/Minecraft:_Java_Edition "Minecraft: Java Edition")_ is one of the two [editions](https://minecraft.wiki/w/Edition "Edition") of _[Minecraft](https://minecraft.wiki/w/Minecraft "Minecraft")_ written in [Java](https://en.wikipedia.org/wiki/Java "wikipedia:Java") and depends on the _[Minecraft Launcher](https://minecraft.wiki/w/Minecraft_Launcher "Minecraft Launcher")_ to download, update, and play. Most of the new development projects focus on either creating entirely new programs from scratch that interoperate with _Minecraft_ (such as a bot or server) or [modding](https://minecraft.wiki/w/Mod "Mod") projects that integrate with the game's [client](https://minecraft.wiki/w/Client.jar "Client.jar") or [server](https://minecraft.wiki/w/Server.jar "Server.jar") and provide bug fixes, new features, and several enhancements to existing features.

### Miscellaneous

\[ [edit](https://minecraft.wiki/w/Java_Edition_protocol?section=6&veaction=edit "Edit section: Miscellaneous") \| [edit source](https://minecraft.wiki/w/Java_Edition_protocol?action=edit&section=6 "Edit section's source code: Miscellaneous")\]

- Data formats – Several data formats to store data readable by machines or humans:
  - [NBT](https://minecraft.wiki/w/Minecraft_Wiki:Projects/wiki.vg_merge/NBT "Minecraft Wiki:Projects/wiki.vg merge/NBT")\[ _[vg](https://minecraft.wiki/w/Minecraft_Wiki:Projects/wiki.vg_merge "Minecraft Wiki:Projects/wiki.vg merge")_\]/ [NBT format](https://minecraft.wiki/w/NBT_format "NBT format")\[ _main_\] – A [tree data structure](https://en.wikipedia.org/wiki/tree_data_structure "wikipedia:tree data structure") and binary data format used in many save files to store arbitrary data.
  - [JSON](https://minecraft.wiki/w/JSON "JSON") – A human-readable data interchange formats used in many data-driven definitions of objects in [resource packs](https://minecraft.wiki/w/Resource_pack "Resource pack") and [data packs](https://minecraft.wiki/w/Data_pack "Data pack").
- Text formatting and styling – Several resources on rendering of text:
  - [Font](https://minecraft.wiki/w/Font "Font") – Defined by [resource packs](https://minecraft.wiki/w/Resource_pack "Resource pack") to change how characters look.
  - [Text component](https://minecraft.wiki/w/Text_component "Text component") – The modern way to define text formatting, such as italic, bold, strike through, colors, and other types of formatting.
  - [Formatting codes](https://minecraft.wiki/w/Formatting_codes "Formatting codes") – The legacy way to define text formatting using the `§` character.
- [Server](https://minecraft.wiki/w/Server "Server")protocols and APIs:

  - [RCON](https://minecraft.wiki/w/RCON "RCON")
  - [Query](https://minecraft.wiki/w/Query "Query")
  - [Minecraft Server Management Protocol](https://minecraft.wiki/w/Minecraft_Server_Management_Protocol "Minecraft Server Management Protocol")
